Эндпоинты API

GET /rdkit/api/adme NEW
ADME / Drug-likeness

Полный набор ADME-свойств и оценки drug-likeness молекулы.

ПараметрТипОписание
smiles *stringSMILES молекулы
Пример запроса: 
GET /rdkit/api/adme?smiles=CC(=O)Oc1ccccc1C(=O)O
Пример ответа:

  "formula": "C9H8O4",
  "molecular_weight": 180.1574,
  "logp": 1.19,
  "hbd": 1,
  "hba": 4,
  "tpsa": 63.6,
  "rotatable_bonds": 3,
  "lipinski_violations": 0,
  "lipinski_pass": true,
  "qed": 0.55,
  "qed_interpretation": "Good (moderate drug-likeness)",
  "sa_score": 2.1,
  "num_rings": 1,
  "num_aromatic_rings": 1,
  "num_heteroatoms": 4,
  "num_atoms": 13,
  "num_bonds": 13,
  "fraction_sp3": 0.1111,
  "num_stereocenters": 0,
  "num_undefined_stereocenters": 0
}
GET /rdkit/api/functional_groups NEW
Функциональные группы

Определяет наличие функциональных групп в молекуле по SMARTS-паттернам.

ПараметрТипОписание
smiles *stringSMILES молекулы
Пример: 
GET /rdkit/api/functional_groups?smiles=CC(=O)Oc1ccccc1C(=O)O
GET /rdkit/api/validate NEW
Валидация SMILES

Проверяет корректность SMILES с подробной диагностикой ошибок.

ПараметрТипОписание
smiles *stringSMILES для проверки
GET /rdkit/api/reaction NEW
Реакции (SMIRKS)

Применяет реакцию (SMIRKS) к молекуле.

ПараметрТипОписание
smiles *stringSMILES реагента
reaction_smarts *stringSMARTS реакции
Пример: 
GET /rdkit/api/reaction?smiles=CC(=O)O&reaction_smarts=[CX3](=O)[OX2H1]>>[CX3](=O)[OX2H0][#6]
GET /rdkit/api/pka NEW
Оценка pKa

Оценивает кислотные/основные центры молекулы.

ПараметрТипОписание
smiles *stringSMILES молекулы
POST /rdkit/api/batch NEW
Пакетный анализ

Анализирует список SMILES за один запрос.

Пример запроса: 
POST /rdkit/api/batch
Content-Type: application/json

{
  "smiles_list": ["CCO", "CC(=O)O", "c1ccccc1"]
}
GET /rdkit/api/by_inchikey NEW
Поиск по InChIKey

Получает свойства молекулы по InChIKey.

ПараметрТипОписание
inchikey *stringInChIKey молекулы
GET /rdkit/api/descriptors NEW
Все дескрипторы RDKit

Возвращает все доступные дескрипторы RDKit (200+).

ПараметрТипОписание
smiles *stringSMILES молекулы
GET /rdkit/api/3d NEW
3D-структура

Генерирует 3D-структуру молекулы в формате SDF, MOL или PDB.

ПараметрТипОписание
smiles *stringSMILES молекулы
formatstringФормат: sdf, mol, pdb (по умолчанию: sdf)
GET /rdkit/api/library NEW
Библиотека молекул

Возвращает список сохранённых молекул.

POST /rdkit/api/compare NEW
Сравнение молекул

Сравнивает несколько молекул попарно (матрица Tanimoto).

GET /rdkit/api/render_highlighted NEW
Рендеринг с подсветкой

Рендерит молекулу с подсветкой функциональных групп.

Примеры молекул

Аспирин
CC(=O)Oc1ccccc1C(=O)O

Ацетилсалициловая кислота — обезболивающее, жаропонижающее, противовоспалительное средство.

Кофеин
CN1C=NC2=C1C(=O)N(C(=O)N2C)C

Кофеин — стимулятор центральной нервной системы.

Ибупрофен
CC(C)Cc1ccc(cc1)C(C)C(=O)O

Ибупрофен — нестероидный противовоспалительный препарат.

Парацетамол
CC(=O)Nc1ccc(O)cc1

Парацетамол — обезболивающее и жаропонижающее средство.
