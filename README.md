# Usage

1. install python3
2. install pip module for python3
3. install venv python3 -m venv .
4. run ./bin/python -m pip install -r reqs.txt in directory with reqs.txt
5. run ./bin/python3 main.py
6. run examples_clients/..jsme.html in firefox/chromium or you browser that you like
It's will works on linux or windows. openbsd is not good for that. Another OS not tested
