Справка по дескрипторам

Базовые свойства

MW (Molecular Weight) — Молекулярная масса

Масса молекулы в дальтонах (г/моль). Важна для определения дозировки и фармакокинетики. Лучше < 500 для лекарств.

LogP (Коэффициент распределения)

Показывает, насколько молекула «любит» жиры (липиды) по сравнению с водой. Высокий LogP = жирорастворимая, низкий = водорастворимая. Для лекарств оптимально 1-3.

TPSA (Topological Polar Surface Area)

Площадь полярной поверхности молекулы (Å²). Влияет на проникновение через мембраны. Меньше 140 Å² лучше для пероральных лекарств.

HBD (H-Bond Donors) — Доноры водородных связей

Количество групп, которые могут отдать водород для связи (OH, NH). Влияет на растворимость и проникновение. Лучше ≤ 5.

HBA (H-Bond Acceptors) — Акцепторы водородных связей

Количество атомов, которые могут принять водород (O, N). Влияет на связывание с мишенями. Лучше ≤ 10.

Лекарственность (Drug-likeness)

QED (Quantitative Estimate of Drug-likeness)

Оценка от 0 до 1 насколько молекула похожа на лекарство. Ближе к 1 = лучше. Учитывает множество свойств одновременно.

SA Score (Synthetic Accessibility)

Оценка сложности синтеза от 1 (легко) до 10 (очень сложно). Ниже = проще синтезировать в лаборатории.

Lipinski's Rule of Five

Набор правил для предсказания пероральной биодоступности: MW ≤ 500, LogP ≤ 5, HBD ≤ 5, HBA ≤ 10. Нарушение ≤ 1 правила допустимо.

Структурные особенности

Rotatable Bonds — Вращающиеся связи

Количество одинарных связей, которые могут свободно вращаться. Влияет на гибкость молекулы. Меньше 10 лучше для пероральных лекарств.

Rings / Aromatic Rings — Циклы / Ароматические циклы

Количество циклических структур. Ароматические циклы (бензол и др.) часто встречаются в лекарствах.

Stereocenters — Стереоцентры

Атомы с четырьмя различными заместителями (хиральные центры). Важны для фармакологической активности — разные изомеры могут действовать по-разному.

Fraction CSP3 — Доля sp³-углеродов

Отношение sp³-гибридизованных атомов углерода к общему числу атомов углерода. Выше = более «3D-подобная» молекула, часто лучше для селективности.

Инструменты анализа

pKa — Константа кислотности

Показывает, насколько легко молекуда отдаёт протон (H⁺). Влияет на заряд молекулы при физиологическом pH и её проникновение через мембраны.

Tanimoto Similarity — Сходство Танимото

Мера сходства двух молекул от 0 до 1. 1 = идентичны, 0 = совершенно разные. Основана на сравнении фингерпринтов.

SMARTS — Поиск подструктур

Язык для описания химических паттернов. Позволяет искать функциональные группы и фрагменты в молекулах. Например, c1ccccc1 — бензольное кольцо.

SMIRKS — Реакции

Язык для описания химических реакций. Показывает, какие атомы изменяются при превращении реагентов в продукты. Используется для моделирования реакций.

Форматы данных

SMILES — Упрощённая запись молекул

Строковое представление молекулы. Например, CCO — этанол, c1ccccc1 — бензол. Удобно для поиска и обмена данными.

InChI / InChIKey — Идентификаторы

Стандартные идентификаторы химических веществ от IUPAC. InChIKey — короткая хэш-строка для быстрого поиска в базах данных.

SDF — Файл структурных данных

Формат для хранения 3D-координат атомов и связей. Используется для обмена молекулярными структурами между программами.
